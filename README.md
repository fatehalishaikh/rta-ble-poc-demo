# Bus Lane Enforcement — prototype demo

A clickable, front-end-only prototype of a bus lane enforcement portal, published here so it can be
opened from a link without installing anything.

**Everything in it is made up.** Every violation, plate, camera, location and figure is synthetic
demonstration data generated in the browser. It is not connected to any live system, it holds no real
records, and it is not an official product of any transport authority.

## About this repository

`index.html` is a generated build — the whole application, with its stylesheet, JavaScript and fonts
inlined into a single file. It is not the source. The source is maintained privately and this file is
replaced wholesale on each update, so there is nothing here to send a pull request against.

Served via GitHub Pages, with a `noindex` directive so it stays out of search results.
